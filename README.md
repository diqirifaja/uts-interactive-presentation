## Deskripsi Proyek
Aplikasi presentasi slide berbasis web interaktif yang membahas kronologi transformasi media digital dari era Web 1.0 hingga era generatif modern tahun 2026. Proyek ini dibangun menggunakan **Reveal.js** dengan manipulasi CSS & Vanilla JavaScript murni.

## Fitur & Interaktivitas
1. **Navigasi Mulus:** Mendukung kontrol keyboard (panah/spasi) dan *swipe* di layar HP.
2. **Video Embed:** Pemutar video YouTube bawaan pada studi kasus awal rilis YouTube.
3. **Audio Simulator:** Pemutar musik khusus berbasis Web Audio API
4. **Micro-interaction:** Tombol "Like" interaktif pada studi kasus Instagram.
5. **Dynamic Data Toggle:** Komparasi infrastruktur jaringan (2000 vs 2026) secara *real-time*.
6. **Live Quiz:** Kuis evaluasi pemahaman audiens dengan feedback instan.

## Cara Menjalankan Secara Lokal
1. Pastikan seluruh file (`index.html`, `style.css`, `script.js`, dan `Alex Crichton - What If I Call.mp3`) berada di dalam satu folder yang sama.
2. Klik ganda pada file `index.html` untuk membukanya di browser (Chrome/Edge/Firefox).
